BW CallMe — Аудио и видеозвонки внутри Telegram WebApp

BW CallMe — это модуль для Telegram, позволяющий совершать аудио- и видеозвонки прямо через WebApp. Использует WebRTC и WebSocket для передачи видео и аудио между пользователями.

⸻

📦 Структура проекта

webapp/
 └─ callme/
     ├─ index.html       # Страница звонка WebApp
     ├─ app.js           # Логика звонка (WebRTC + WS)
     ├─ style.css        # Стили интерфейса
     ├─ callme.json      # Хранилище данных пользователей
     └─ avatar/          # Сохранённые аватары пользователей (tgid.jpg)
callme.py                # Telegram bot module
.env                     # Настройки TURN/STUN сервера

	•	callme.json — хранит информацию о пользователях: id, name, username, avatar.
	•	avatar/ — сохраняются аватары пользователей по TGID (tgid.jpg).
	•	.env — переменные для TURN/STUN:

TURNIP=127.0.0.1
TURNLOGIN=login
TURNPASSWORD=password

⚙️ Установка
	1.	Клонируйте репозиторий:

git clone https://github.com/bwproject/BW-TG-CALL-APP.git
cd BW-TG-CALL-APP

	2.	Установите зависимости Python:

pip install aiogram fastapi uvicorn aiohttp

	3.	Создайте .env с вашими TURN/STUN настройками.
	4.	Запустите бота:

uvicorn callme:app --reload


⸻

📝 Настройка Telegram Bot
	•	Создайте бота через BotFather￼.
	•	Вставьте токен в .env (или в конфигурацию бота).
	•	Бот использует команды:

Команда	Описание
/callme	Начало звонка. Если указан TGID, отправляет запрос на звонок другому пользователю.
/callmeinfo	Информация о модуле и ограничениях Telegram WebApp.


⸻

📲 Как работает
	1.	Пользователь вызывает /callme <TGID>.
	2.	Получатель видит входящий звонок с кнопками Принять / Отклонить.
	3.	После принятия создаётся WebApp со страницей звонка:
	•	Локальное видео и аудио
	•	Динамическая кнопка ВНИМАНИЕ с описанием ограничений
	•	Управление камерой, микрофоном, переключение камеры и динамика
	•	Отображение аватара собеседника (если он есть в callme.json)
	4.	WebRTC передает видео и аудио, а WebSocket синхронизирует обмен SDP и ICE кандидатами.

⸻

🎨 Интерфейс WebApp
	•	Видео: localVideo и remoteVideo
	•	Аватар: avatar (локальный), remoteAvatar (собеседника)
	•	Кнопки управления:
	•	Переключение камеры
	•	Включение/выключение видео
	•	Мут микрофона
	•	Громкая связь
	•	Завершение звонка

⚠️ Примечание: Камера и микрофон запрашиваются только по кнопке. Автостарт невозможен.

⸻

📂 Работа с callme.json
	•	Пример структуры:

{
  "123456": {
    "id": 123456,
    "name": "Юзер",
    "username": "user123",
    "avatar": "/callme/avatar/123456.jpg",
    "updated_at": 1700000000
  },
  "654321": {
    "id": 654321,
    "name": "Юзер2",
    "username": "user456",
    "avatar": null,
    "updated_at": 1700000100
  }
}

	•	Автоматически создается при первом вызове /callme.
	•	Автоматически сохраняются аватары пользователей в avatar/<TGID>.jpg.

⸻

🔗 TURN/STUN
	•	Используется для корректной работы WebRTC на мобильных устройствах.
	•	Настройки берутся из .env:

TURNIP=127.0.0.1
TURNLOGIN=login
TURNPASSWORD=password

	•	Поддерживаются iOS и Android.

⸻

⚠️ Ограничения Telegram WebApp
	•	Автостарт звонка невозможен
	•	Камера и микрофон доступны только по действию пользователя
	•	Переключение динамика зависит от возможностей ОС
	•	Сворачивание WebApp может остановить звук и видео
